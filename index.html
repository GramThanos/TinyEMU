TinyEMU builds

Release builds of TinyEMU (MIT): a system emulator with a software x86 CPU and RISC-V that boots Linux, natively or in the browser as WebAssembly.

WebAssembly engine

One engine runs both the PC (x86) and RISC-V machines. Other sites can load it from here directly. Pin a version rather than latest/, since a release can change the engine's JS API:

engine/<version>/x86emu-wasm.js
engine/<version>/x86emu-wasm.wasm

It needs WebAssembly exception handling: Chrome 95+, Safari 15.4+, Firefox 131+. The JavaScript runtime that drives it (VMs, volumes, snapshots, networking) is jsLab:

import { VMManager } from './jsLab/lib/vm/index.js';
const vms = new VMManager({ urls: {
  wasmJsUrl:  'https://gramthanos.github.io/TinyEMU/engine/<version>/x86emu-wasm.js',
  wasmBinUrl: 'https://gramthanos.github.io/TinyEMU/engine/<version>/x86emu-wasm.wasm',
} });

Native binaries

temu-linux-x86_64.tar.gz holds temu-soft (software x86 CPU + RISC-V) and temu-kvm (x86 through KVM). temu-windows.zip holds temu.exe with its DLLs. Guest images: TinyEMU-distros.
